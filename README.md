Midnight Duo — an offline cover maker that turns your photos into a neon-night, GTA 6-style multi-panel cover: a photographic hero duo on the left, four story snapshots on the right, and a one-line gradient title over a dusk bay. Seven layouts, seven grades (photographic by default, poster ink optional), four export sizes, per-panel captions, undo/redo, drag-pan and wheel-zoom, one-click PNG export. Fully offline — no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Drop your own photos or use the five AI-generated samples in the tray.
